    화면 사용법
    1
    전국 현황 파악
    상단 KPI 스트립에서 CEI 평균·VoC·고객 등급 분포와 주간 추이를 확인합니다. 필터 적용 시 수치가 함께 갱신됩니다.
    2
    대상 좁히기
    운용팀 선택·주소 검색으로 범위를 좁힙니다. 시군구 Bad CE Top 10으로 열위 지역을 바로 이동할 수 있습니다.
    3
    지도 탐색
    히트맵을 확대하면 건물 마커와 구역 통계가 나타납니다. 건물을 클릭하면 해당 건물이 선택됩니다.
    4
    건물 테이블·상세 확인
    하단 데이터 테이블에서 건물별 CEI·Bad CE·VoC 현황을 확인합니다.
    5
    AI 분석·보고
    [AI 분석 실행] 또는 상단 AI Insight 버튼으로 진단 리포트를 생성하고, 추가 질문 후 메일로 발송합니다.
    1
    추출 조건 설정
    운용팀·국사와 열위 factor(Bad CE·VoC·광파워·RTT 등)를 선택하고 [추출]을 누릅니다. 건물 직접 입력도 가능합니다.
    2
    조치 대상 확인
    조치 대상 테이블에서 건물을 선택(체크)합니다. 현재 조건 기준 Top 50 장표를 다운로드할 수 있습니다.
    3
    지시서 발행
    선택한 건물로 [지시서 발행]을 누르면 담당 조직에 지시서가 생성되고 상단 통계(발행·완료·리드타임)에 반영됩니다.
    4
    상태 관리·결과 등록
    지시서 진행 보드를 상태 칩(발행·조치완료·검증완료·중단)으로 필터하고, 조치 결과를 등록합니다.
    5
    조직별 실적 확인
    하단 조직별 실적에서 팀별 처리 현황과 재진단 CEI 개선을 확인하고, 세부 장표를 다운로드합니다.
    1
    장비 리스트 업로드
    조치한 장비 리스트 엑셀(xlsx/csv)을 업로드합니다. 모든 셀을 훑어 장비 ID로 인식하므로 헤더가 있어도 무방합니다.
    2
    직접 입력 (선택)
    관리번호 또는 TID를 쉼표/줄바꿈으로 직접 입력할 수도 있습니다. 파일과 함께 쓰면 파일이 우선합니다.
    3
    기준일 설정
    조치일을 기준일로 지정합니다. 미지정 시 전/후 데이터가 모두 있는 최근 날짜가 자동 사용됩니다.
    4
    전후 비교 조회
    [전후 비교 조회]를 누르면 상단 요약(전/후 CEI 평균·변화·매칭 장비/가입자)과 기준일 전후 트렌드 차트가 표시됩니다.
    5
    장비별 상세 확인
    장비별 전후 비교 테이블에서 장비 단위 Δ(변화량)와 등급 변화를 확인해 조치 효과를 검증합니다.
